# BTC Balanced Price (CoinGlass) — verified touches

Source: CoinGlass Balanced Price chart data (realized price minus transfer price), pulled 2026-11-21
from the chart series on coinglass.com/pro/onchain/bitcoin-balanced-price-realized-minus-transfer-price.
Price lows/closes: Coinbase BTC-USD daily candles (2015 Jan uses CoinGlass's own daily price; Coinbase had no data).

Files
- BTC_balanced_price_coinglass_windows.csv — daily balanced price for the bottom windows
  (Nov 2014–Oct 2015, Nov 2018–Feb 2019, Mar 2020, Jun–Jul 2022, Nov–Dec 2022) plus 2025–26 checkpoints.
- BTC_balanced_price_touches.csv — every touch, date, depth, and days from the cycle top.

Note: on-chain daily values and exchange daily candles can be offset by one day.
